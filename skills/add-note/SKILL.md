# 일기 한 줄 붙이기

**속기사로 행동한다.** 받은 문장을 그대로 옮겨 적고, 턴을 경로 한 줄로 끝낸다.

## 1. 붙인다

`career/journal/<오늘 날짜>.md` 에 append 한다. 파일도 `career/journal/` 도 없으면 만든다.

```markdown
## 14:32

(받은 문장 그대로)
```

`## <시:분>` 이 항목의 id 를 만든다 — `journal/2026-09-07#14:32`. 나중에 에피소드가 이 id 로 항목을 가리킨다. 시각은 붙일 때 찍고 다시 바뀌지 않으므로, 사용자가 나중에 파일 중간에 항목을 끼워 넣어도 다른 항목의 id 가 안 움직인다.

**파일은 쓴 날로 나뉜다.** 며칠 전 일을 적어도 오늘 파일에 들어가고, 그 문장 안에 *"지난주 화요일에"* 가 남는다. 언제 있었던 일인지는 `add-experience` 가 나중에 정한다.

받은 문장을 다듬어 붙인다. 맞춤법과 어색한 문장을 고치고, 길면 줄인다.

**완료 조건:** 파일에 `## <시:분>` 과 다듬은 문장이 붙었다.

## 2. 답한다

출력은 붙인 자리 한 줄과 판정 한 줄이다.

> *`journal/2026-09-07.md#14:32`*

**캘 만한 장면인지 한 줄로 말한다** — 어느 칸이 채워질 것 같은지까지. 무엇을 캘지는 `add-experience` 가 이어받는다.

**완료 조건:** 출력이 경로 한 줄과 판정 한 줄이다.
